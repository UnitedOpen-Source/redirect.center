## English

redirect.center is a free DNS-based domain redirect service. Redirect URLs,
domains, and subdomains using only CNAME records. No server configuration needed
— just point your DNS and go. Supports HTTP 301, 302, 307, 308 redirects, path
forwarding, query strings, HTTPS, and custom ports.

strings, HTTPS e portas personalizadas.
