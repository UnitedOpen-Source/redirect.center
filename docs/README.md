# Desvio — documentação

Desvio é a interface e extensão deste fork do **redirect.center**. O serviço lê
registros DNS e responde com redirecionamentos HTTP. O visitante não precisa
executar JavaScript; a interface apenas ajuda a montar a configuração e
consultar os contadores.

- [Guia de uso e DNS](USAGE.md)
- [Execução local, arquitetura e publicação](DEVELOPMENT.md)
- [Textos multilíngues preservados](LEGACY-CONTENT.md)
- [Revisão das issues e PRs históricos](HISTORY-REVIEW.md)

Na interface, abra **Como funciona** para ver exemplos, referência dos sete
parâmetros DNS e descrições em 12 idiomas. O seletor traduz a interface em
português, inglês ou espanhol.

## Nome e identidade

**Desvio** é o nome da interface deste fork. A identidade usa laranja,
superfícies claras e um símbolo de mudança de direção. A marca é definida por
`PROJECT_NAME`, enquanto `FQDN` define o domínio técnico do serviço. Alterar a
marca não muda os registros DNS existentes. Nenhum novo domínio foi comprado ou
configurado.
